社区插件索引随 dsh-web 家族对齐到统一版本。本版本收录八条社区插件条目，两条既有条目的商店文案同步到上游当前能力，插件组合包的 `@deepseek-ai` 依赖推进到 `0.2.1-rc.2`。

> **重要变更**：插件组合包的最低 DSH 版本上移到 `>=0.2.1-rc.2`（`dsh.engines.dsh` 与 `@deepseek-ai/dsh` peer 一起移动）。本版本没有重命名任何已持久化的标识符、线协议字段或 profile 格式，也没有需要手工迁移的改动。包名 `@linxin666/dsh-client-ui-community-plugins` 与安装方式不变；`community.json` 是工坊商店插件列表与 dsh-market.com 插件清单的唯一数据源。索引条目总数从 132 增至 140；bundle patch 里那行惰性 `ui-community-plugins` 行保持不变。

### 新功能

- 收录嵌入式硬件沙盒 `dsh-breadboard`：在 3D 面包板场景里摆放 ESP32 / BME280 / PIR / LED，按协议与电压校验接线，再让真实 Python 项目代码在环运行，支持故障注入
- 收录连接卡片宿主 `dsh-connection-card-host`：把「连接」做成 DSH 里的一等对象，会话是节点、连接是容器，卡片按连接挂载，两端可按方向分配权限互发消息
- 收录地址栏深链 `dsh-url-router`：会话、面板、设置小节与页签、会话内视图、轨迹行、轮次、右栏 pane 都写进地址栏，侧边栏会话行变成浏览器原生可用的真链接
- 收录侧边栏工作区运行标记 `dsh-workspace-activity`：工作区行显示其下会话的运行状态，只贡献一张样式表，不替换侧边栏组件
- 收录启动视频皮肤 `dsh-web-start-ui`：打开 DSH 时的全屏启动动画，宿主半区在首绘前起播、浏览器半区接管同一个 `<video>`，设置页可选皮肤、上传与预览
- 收录 flash 级精简预设 `dsh-flash-presets`：`flash-lean-ptc-v2`（现行推荐）与 `flash-lean-ptc-v1` 两个 token 效率优化 agent 预设，以组合包形式随 profile 生效
- 收录 TRAE CN 反代与控制台 `dsh-trae-relay`：支持自动签到、多账号轮询、模型发现与思考档位；自动签到与轮询默认关闭
- 收录 Token 用量统计 `dsh-clear-usage`：本地会话历史用量面板，侧重 DSH 原生缓存命中口径、今天的小时活动与 Token 构成

### 修复

- 同步 `dsh-workbench` 条目的商店文案到当前功能集：补上「未入记录」产物的收编、`【打开这一版】` 等已存在能力，去掉与现状不符的描述
- 同步 `dsh-archived-chats` 条目的商店文案到上游当前能力：改以搜索、原生预览、标签备注、工作区归档、ZIP 备份、回收站、空间与保留策略、来源分支为表述，不再把能力限定在「已归档」会话

### 其他改动

- 插件组合包依赖推进到 `@deepseek-ai` `0.2.1-rc.2`（含此前 `0.2.1-alpha.5` 那一步）：`dsh.engines.dsh` 与 `@deepseek-ai/dsh` peer 上移到 `>=0.2.1-rc.2`，十一个 SDK devDependency 与 `@deepseek-ai/cordis` 同步移动，lockfile 从干净解析重建
- `shared/web-platform.ts`：宿主共享模块表按 0.2.1 线补齐 `zod` 与 `@tanstack/react-virtual` 两行，出处注释改记 0.2.1-rc.2 组合包
- README 双语徽章改为 DSH `>=0.2.1-rc.2`
- Agent Note：记录 2026-10-12、2026-10-13、2026-10-16 三个注册轮次与 relay 插件准入决定，以及 `0.2.1-alpha.5` 与 `0.2.1-rc.2` 两次组合包迁移
- 本包不构建客户端 bundle，`lib/index.js` 较上一版本逐字节一致

The community plugin index publishes on the family's aligned version. This release registers eight community plugin entries, syncs the store copy of two existing entries with their current upstream capabilities, and advances the plugin bundle's `@deepseek-ai` dependencies to `0.2.1-rc.2`.

> **Important change**: the bundle's minimum DSH version moves to `>=0.2.1-rc.2` (`dsh.engines.dsh` and the `@deepseek-ai/dsh` peer move together). No manual migration is needed, and no persisted identifier, wire-protocol field or profile format was renamed. The package name `@linxin666/dsh-client-ui-community-plugins` and its install path are unchanged; `community.json` remains the single data source for the Workshop store plugin list and the dsh-market.com plugin manifest. The index grows from 132 to 140 entries; the inert `ui-community-plugins` row of the bundle patch is unchanged.

### New Features

- Register the embedded hardware sandbox `dsh-breadboard`: place ESP32 / BME280 / PIR / LED components on a 3D breadboard scene, wire ports with protocol and voltage checks, then run real Python project code in the loop, with fault injection
- Register the connection card host `dsh-connection-card-host`: makes a connection a first-class object in DSH, with sessions as nodes, connections as containers and cards mounted per connection, plus direction-scoped permissions and cross-session messaging
- Register the URL deep links plugin `dsh-url-router`: conversations, panels, settings sections and tabs, conversation views, trajectory rows, turns and right-bar panes each get an address-bar link, and sidebar conversation rows become real browser links
- Register the sidebar workspace activity marker `dsh-workspace-activity`: workspace rows show the run state of their sessions, contributing one stylesheet instead of replacing the sidebar component
- Register the launch video skin `dsh-web-start-ui`: a full-screen launch animation whose host half starts the video before first paint and whose browser half adopts that same `<video>`, with skin selection, upload and preview in settings
- Register the flash-tier lean presets `dsh-flash-presets`: two token-efficiency agent presets, `flash-lean-ptc-v2` (the current recommendation) and `flash-lean-ptc-v1`, applied per profile as a bundle
- Register the TRAE CN relay and console `dsh-trae-relay`: daily check-in, multiple accounts with rotation, model discovery and reasoning levels; automation stays off by default
- Register the token usage dashboard `dsh-clear-usage`: a local session-history usage panel focused on DSH-native cache-hit accounting, today's hourly activity and token composition

### Bug Fixes

- Sync the `dsh-workbench` entry's store copy with the current feature set: add the "not in the record" adoption flow and `Open this build`, and drop descriptions that no longer match
- Sync the `dsh-archived-chats` entry's store copy with the upstream's current capabilities: describe search, native previews, tags and notes, workspace archiving, ZIP backups, the Recycle Bin, storage and retention policies and origin branches instead of restricting it to archived conversations

### Other Changes

- Advance the bundle's `@deepseek-ai` dependencies to `0.2.1-rc.2` (including the earlier `0.2.1-alpha.5` step): `dsh.engines.dsh` and the `@deepseek-ai/dsh` peer move to `>=0.2.1-rc.2`, the eleven SDK devDependencies and `@deepseek-ai/cordis` move with them, and the lockfile is rebuilt from a clean resolution
- `shared/web-platform.ts`: the host's shared module table gains the `zod` and `@tanstack/react-virtual` rows of the 0.2.1 line, and its provenance comment now cites the 0.2.1-rc.2 cohort
- README: the bilingual badge moves to DSH `>=0.2.1-rc.2`
- Agent Notes: record the 2026-10-12, 2026-10-13 and 2026-10-16 registration rounds and the relay plugin acceptance decision, plus both cohort moves, `0.2.1-alpha.5` and `0.2.1-rc.2`
- This package builds no client bundle, so `lib/index.js` is byte-identical to the previous release
